# Machine Dog

A ROS 2 quadruped robot project for learning robotics engineering.

## Project Goals

This project will gradually implement:

- quadruped robot simulation
- robot control
- sensors
- odometry
- localization
- localization testing
- SLAM
- navigation

## Development Environment

- WSL2 Ubuntu
- ROS 2
- Gazebo
- RViz2
- VSCode
- Git
- GitHub
